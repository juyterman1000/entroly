# Cost, quality and cache economics: evidence boundaries

Baseline `1de499a58835f13eba923a89a8020a9e43eed92e`.

## What is verified

- Bundled catalogs exist for Anthropic, OpenAI and Gemini, with declared source URL and `verified_at`.
- OpenAI's published [API pricing page](https://developers.openai.com/api/docs/pricing) lists the Standard text token rates included in `entroly/data/openai_pricing.json` for the named flagship models at the time of review.
- Google's [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing) describes Standard paid-tier input/cache prices and the over-200k input tier for 3.1 Pro; the stored catalog handles this tier.
- The code intentionally withholds a conservative dollar estimate for unpriced models/request sizes. Reported dollar values concern the input side only and are estimates, not provider invoices.
- Pre-merge CI included `tests/test_net_savings.py`, provider stub receipt tests, and the benchmark workflow. No new invoice-backed A/B was executed.

## What is not verified

| Metric | Value | Reason |
| --- | --- | --- |
| Real-provider baseline cost | NOT MEASURED | No authorized paid provider traffic |
| Real-provider Entroly cost | NOT MEASURED | No paired traffic and billing |
| Measured provider cache savings attributable to Entroly | NOT MEASURED | A stub cannot establish a real billing counterfactual |
| Cost per successful agent task | NOT MEASURED | No live agent A/B/C tasks |
| Agent accuracy, completeness and retries | NOT MEASURED | No task-quality oracle |
| p50/p95/p99 end-to-end latency | NOT MEASURED | No independent complete agent trace |
| Unpriced request coverage in production | NOT MEASURED | No production receipts |

Do not quote PR #588's 64-request stub saving figures as production invoice validation. Cache-read discounts generated by a provider alone are not Entroly savings.

## Required ledger contract

`conservative_net_saving = eligible_removed_input_value - added_input_charges - cached_prefix_interference_charges`.

Every reported claim requires provider, model ID, exact pricing source, catalog verification date, input size/tier, usage evidence, measurement coverage and limitations. Reject nonfinite or invalid custom rate strings before they can enter receipt accounting. The accompanying fix makes invalid catalog data unpriced rather than allowing exceptions or nonfinite values.

## Independent gate

Perform at least one representative pre-registered task set per supported live provider and compare `no-Entroly`, default, and tuned settings. Measure billable input, output, cache reads/writes, retries, cache hit rate, successful completions, p95 latency and actual invoices where available. Store aggregate findings, not sensitive prompts.
