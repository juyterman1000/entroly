# Evidence-bounded value attribution

Entroly explains request value by mechanism while preserving the canonical accounting tiers: measured, estimated, and opportunity. Attribution is explanatory unless the accounting kernel marks it additive or an adjustment. Recovery and re-expansion remain debits against measured gross savings. Request-local attribution is bounded, content-free, lifecycle-safe, and must project consistently into Traffic Receipts, Traffic Value, metrics, logs, CLI, and dashboard surfaces.
