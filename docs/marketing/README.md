# Entroly launch and outreach assets

This directory contains reusable drafts for external launch and discovery
channels. It is not evidence that a post, listing, review, or submission exists.

## Rules

- Disclose maintainer affiliation.
- Link the repository, exact install command, limitations, and reproducible demo.
- Lead with product mechanics and user problem, not a universal percentage.
- Do not quote stars, downloads, users, savings, or competitor rankings unless
  the source and measurement window are current and linked.
- Do not coordinate artificial votes, comments, stars, or engagement.
- Preserve criticism and negative results in public technical discussions.
- Record a public URL in `docs/distribution/targets.json` only after submission.

## Launch order

1. Publish repository and documentation improvements.
2. Confirm the released package is available through its advertised channels.
3. Run `entroly verify-claims` and verify every command in the draft.
4. Publish one technical launch at a time.
5. Answer questions with evidence and limitations.
6. Record the URL and outcome in the distribution registry.
