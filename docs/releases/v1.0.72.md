# Entroly 1.0.72

Entroly 1.0.72 packages the production-grade defaults and operations work merged through PR #251.

Highlights:

- identity-first SDK behavior for requests that already fit the effective provider budget;
- secure recovery-store wiring across public runtime entry points;
- explicit CA trust without ambient proxy inheritance;
- atomic, reversible agent wrapping with surgical `unwrap`;
- privacy-safe `capabilities --json`, `status --json`, and `doctor --json` diagnostics;
- executable, fail-closed provider conformance checks;
- consistent Python, Rust, WASM, npm, MCP, OpenClaw, and packaging version surfaces.

The release version sweep is generated by `scripts/bump_version.py` and validated by the release-surface tests. Historical benchmark and release records retain the versions under which they were produced.
