# Entroly 1.0.70

Entroly 1.0.70 strengthens the evidence-control path used to decide what an
agent sees under a hard context budget.

## Context selection certificates

- Context Receipt selection now treats each fragment and its transitive resolved
  dependencies as an atomic bundle.
- Candidate frontiers with at most 14 positive roots are solved exactly for the
  declared internal retrieval-score objective.
- Larger frontiers deterministically choose the better of rank-order and dynamic
  marginal-score-per-token packing, then report a conservative relaxed regret
  bound instead of claiming exact optimality.
- Receipts include feasibility checks, optimizer status, the rank-order control
  score, and a digest-bound recovery frontier for omitted bundles.
- Python and Rust produce identical selection certificates and certificate
  hashes on the cross-backend contract probe.

The [committed exhaustive artifact](../../benchmarks/results/closed_set_selection_frontier.json)
covers 47,862 declared small graph, token cost, and budget cases. Rank-order
packing was suboptimal in 378 cases; the new selector improved all 378,
regressed in zero, matched the independent exact oracle in all 47,862, and
emitted zero partial dependency closures, budget violations, or invalid
certificates. This is a synthetic internal-objective result, not an
answer-quality or competitor claim.

## Source-authenticated receipts

- Selected and omitted fragments carry exact UTF-8 byte ranges plus independently
  recomputable source and fragment SHA-256 digests.
- Python and native ingestion preserve byte-exact fragment recovery across the
  committed fidelity corpus.
- Receipt-backed public SDK recovery is covered by a separately checksum-bound
  artifact.

## Reliability and research discipline

- MCP dogfood tests continuously drain subprocess pipes so transport-heavy runs
  cannot deadlock on captured output.
- Static codebase graph and symbol-delivery artifacts make code-agent context
  claims reproducible.
- The neural evidence study keeps its negative result public: the evaluated
  generic MiniLM primary scorer did not beat BM25 on the declared corpus.
- A dated primary-source literature map defines the prior-art boundary for graph
  memory, provenance, compression, cache economics, workflow memory, and world
  models.

## Compatibility and upgrade

No configuration migration is required. The receipt schema change is additive;
existing readers that ignore unknown `risk_summary` fields continue to work.
Python, Rust, npm, MCP, OpenClaw, WASM, plugin, Docker, and release metadata are
synchronized to 1.0.70.

The live Homebrew formula intentionally remains pinned to 1.0.69 until the
1.0.70 PyPI source archive exists and the post-release workflow can update the
URL and checksum atomically.
