# Entroly 1.0.75

Release metadata for Entroly 1.0.75 is synchronized across Python, Rust,
npm, MCP, OpenClaw, WASM, plugin, Docker, Homebrew, and GitHub release
surfaces.

This release also hardens agentic benchmarking with a mandatory null-context
control and rejects collection, import, timeout, and runner failures as mined
task oracles.

The canonical bump tool completed the full active-target inventory, including
all Python/Rust/WASM/npm manifests, workspace Cargo lock entries, runtime
fallbacks, native minimums, MCP/OpenClaw/plugin metadata, and release tests.

See the GitHub release and merged pull requests for the complete feature,
security, compatibility, and migration notes.
