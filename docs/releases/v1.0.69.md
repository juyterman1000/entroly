# Entroly 1.0.69

This patch release makes Entroly's release state deterministic:

- synchronizes active Python, Rust, npm, MCP, OpenClaw, WASM, and plugin
  manifests, including native dependency floors and OpenClaw install guidance;
- keeps the live Homebrew formula on its last verified artifact until the
  post-PyPI workflow can atomically write the real 1.0.69 URL and checksum;
- removes the obsolete one-shot 1.0.68 synchronizer before it can downgrade a
  later release; and
- makes MCP protocol tests deterministic by isolating optional federation state
  and continuously draining subprocess output on Windows.

No migration is required from 1.0.68.
