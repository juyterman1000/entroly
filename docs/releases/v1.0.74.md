# Entroly 1.0.74

Entroly 1.0.74 synchronizes release metadata across the supported Python, Rust,
npm/WASM, MCP, OpenClaw, plugin, server, Homebrew-runbook, and packaged MCPB
surfaces.

This release also restores consistency between the public compression-frontier
evidence, its canonical generator, and the recovery-evidence regression
contracts. The committed benchmark artifacts remain verifier-backed and use
neutral external-baseline labels on public surfaces. Generated tables and
charts keep those neutral display labels while stable machine-readable
participant identifiers remain unchanged for verifier compatibility.

## Validation

The release is gated by the repository's Python-version matrix, pure-Python
fallback, Rust and WASM checks, benchmark evidence verification, public-trust
contracts, agent integration contracts, OpenClaw validation, and deep dogfood
workflows.

The canonical Homebrew formula remains pinned to the last verified published
sdist until the post-publication workflow can update its URL and checksum
atomically.
