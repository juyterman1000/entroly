# Entroly 1.0.67

Entroly 1.0.67 prepares synchronized release metadata across the active Python,
Rust, npm, MCP, OpenClaw, WASM, Claude-plugin, Docker, Homebrew-runbook, and
GitHub release surfaces.

## Included changes

- Evidence-bounded agent compatibility documentation and setup classifications.
- Modern GitHub Copilot CLI custom-provider and scoped MCP attachment contracts.
- Cost-led Context Assurance positioning with explicit provider-routing and
  subscription boundaries.
- Updated model and discovery metadata already merged into the release source.
- Version parity across runtime fallbacks, manifests, lockfiles, generated MCPB,
  and release-surface tests.

## Boundaries

This source version does not by itself prove that PyPI, npm, ClawHub, MCP
registries, Docker, GitHub Releases, or Homebrew have published 1.0.67. Live
registry propagation and the Homebrew formula checksum are validated by the
post-merge release workflows.

Historical benchmark artifacts and prior investigation records remain unchanged.
